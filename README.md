## Sobre
Esse projeto foi desenvolvido para aula de robótica computacional com intuito de praticar conhecimentos sobre Arduino. Consite em um timer, onde o usuário digita em um teclado os minutos e os segundos que deseja, a contagem regressiva aparece em uma tela lcd. Quando o tempo chega ao fim, um buzzer toca e um led acende. O sistema também mostra a temperatura no led.

## Materiais
- Arduino Uno
- Teclado numérico
- Tela LCD
- Placa protoboard
- Buzzer
- Led
- Relógio RTC
- Sensor de temperatura DHT11
